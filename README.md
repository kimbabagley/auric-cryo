# Auric Cryo

Demo catalog. Not a live store. No orders are placed.

For laboratory research use only. Not for human consumption.

Static Next.js export for a free GitHub Pages preview. The checkout walks contact, shipping and review, then stops: payment is not connected and no orders are placed.
